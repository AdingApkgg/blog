## Introduction

Installing [原神私服](https://blog.saop.cc/p/ea5c/) mods is only supported on Windows—if you're on any other system, please exit this tutorial!

You'll need a little bit of computer knowledge (really—just a little), otherwise please exit this tutorial, thanks!

If you run into any problems during the process, leave a comment. Don't want to follow the tutorial? (Then why are you even playing with mods? Please exit this tutorial.)

Do not use mods on official servers—you will get banned!!

Do not apply multiple mods to the same character, weapon, or other item. At best you'll get bugs (model twitching); at worst the game crashes, your computer blue-screens and dies, and your PC is ruined!!

Delete all antivirus software, or just turn it off (assuming you can actually turn it off).

## Using the mod tools

> 123 Cloud Drive (extraction code: saop.cc): https://www.123pan.com/s/VMelVv-MI1zH.html
>
> Tianyi Cloud Drive (access code: 0gx0): https://cloud.189.cn/web/share?code=3yuUbiQFFV73

Download the `YS MOD.zip` archive from the cloud drive, extract it to any folder or drive partition, then go into the `YS MOD` > `3dmigoto` folder.

![3dmigoto文件夹](/img/202304230046952.webp)

Use `记事本` to edit the `d3dx.ini` file, press <kbd>Win</kbd> + <kbd>F</kbd> to open the search box, search for `YuanShen.exe` and click Find.

![d3dx.ini](/img/202304230048511.webp)

Replace `Z:\ys\yscn\Genshin Impact\Genshin Impact Game\YuanShen.exe` with the executable path of your Genshin Impact private server game `YuanShen.exe`, then press <kbd>Ctrl</kbd> + <kbd>S</kbd> to save and exit.

Refer to the reserved path `Z:\ys\yscn\Genshin Impact\Genshin Impact Game\YuanShen.exe` for how to fill in the path—don't tell me you can't do it (please exit this tutorial).

Then right-click the `3DMigoto Loader.exe` executable in the folder and run it as administrator to launch the mod tool. Next, enter your Genshin Impact private server game. When entering, listen carefully for a `滴~` sound—if you hear it, the mod tool is running properly. If it crashes, just enter a few more times. Once you're in the game and able to control your character, switch through a few female characters to see the results 😏~

![雷神の私服](/img/202302212248058.webp)

<kbd>ins</kbd> or the numeric keypad <kbd>0</kbd> toggles the mod software's info overlay, and <kbd>u</kbd> hides the Genshin Impact UI.

If none of these work, figure out which key does it yourself.

If you've installed too many mods, lots of info messages will pop up when you enter the game—just wait a moment and they'll disappear.
