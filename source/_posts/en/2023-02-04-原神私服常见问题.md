## Notes

> This page collects solutions to various common problems with Genshin Impact private servers
>
> If your problem still isn't resolved, feel free to leave a comment for feedback

## Problems and Solutions

{% hideToggle 4212、4214错误, blue %}

Case 1: The patch wasn't applied, or the wrong one was applied — check it yourself

Case 2: The private server `游戏版本` is too old; please update it

{% endhideToggle %}

{% hideToggle 进门后显示连接超时, cyan %}

It's probably that `服务器` is under attack or has shut down; in the former case, wait a while before going online again, in the latter, switch to another `服务器`

{% endhideToggle %}

{% hideToggle 进门后白屏, green %}

Case 1: It's probably that `服务器` is under attack or has shut down; in the former case, wait a while before going online again, in the latter, switch to another `服务器`

Case 2: The account is dead; use a different account name to log in again

{% endhideToggle %}

{% hideToggle 4206错误, yellow %}

It may be a problem with `服务器`; switching servers is recommended

{% endhideToggle %}

{% hideToggle 登录账号提示网络错误/网络超时, red %}

It may be a problem with `服务器`; switching servers is recommended

{% endhideToggle %}

{% hideToggle 点击登录转圈然后没反应, blue %}

Delete everything and start over; if once doesn't work, do it twice!

{% endhideToggle %}

{% hideToggle 开启代理后还是登的官服, cyan %}

Possibly the Win7 system is too old; please upgrade to Win10

If not, turn off or uninstall all antivirus software

Then delete everything and start over; if once doesn't work, do it twice!

{% endhideToggle %}

{% hideToggle 4201、-9203错误, green %}

Possibly the Win7 system is too old; please upgrade to Win10

If not, turn off or uninstall all antivirus software

Then delete everything and start over; if once doesn't work, do it twice

{% endhideToggle %}

{% hideToggle 卡检查更新, yellow %}

Delete everything and start over; if once doesn't work, do it twice; if that still doesn't work, change phones

{% endhideToggle %}

{% hideToggle 进入 SF 服务器后 “准备加载数据” 卡 “45%”, red %}

The cause is that the resources weren't fully downloaded

{% endhideToggle %}

{% hideToggle 为什么不能回血, blue %}

Case 1: It's a server problem; switch to another server

Case 2: It may also be an issue with the current private server version — you could say it's a feature

Just use the command `/h` to heal everyone with one click

{% endhideToggle %}

{% hideToggle Win7系统代理工具兼容性问题, cyan %}

If Win7 isn't compatible with the proxy software, you can try the miHoYo proxy redirect (look for it in the cloud drive)

{% endhideToggle %}

{% hideToggle 服务器繁忙，请稍后再试(502), green %}

The server may be under attack; try logging in later or switching to another server...

{% endhideToggle %}

{% hideToggle 指令怎么用，在哪用？, yellow %}

A newly created account will always have one friend in its friend list,

{% note info %}

If there's no friend, it may be a grind server; please switch to a command server

{% endnote %}

Then just send it the commands you need

{% endhideToggle %}

{% hideToggle 指令用不了, red %}

The server you're playing on may be special, and some commands are used differently from standard ones,

Please find the server-specific commands or command generator yourself,

Or switch to another server that follows the command standard

{% endhideToggle %}

{% hideToggle 二级地址解析失败, blue %}

The server is probably under maintenance or has run off; try again later

{% endhideToggle %}
