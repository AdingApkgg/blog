[rsync](https://samba.anu.edu.au/rsync/) is an open-source tool for fast incremental file transfer.

Lately I've been transferring files frequently while using Linux, so I use rsync to meet my needs..

Here I'll record the commands I commonly use with rsync.

```sh
rsync -ravzP ~/test i@i.cc:/home/i/

```

Sync the local test folder to the remote machine

```sh
rsync -ravzP i@i.cc:/home/i/test ~/

```

Sync the remote test folder to the local machine
