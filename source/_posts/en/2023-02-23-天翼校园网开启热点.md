## Preface

Most students on campus probably know very well that Tianyi Campus Network allows only one account on one device.

I have no idea why such a restriction exists; this alone severely affects students' daily use!

That's not all—you can't even turn on a mobile hotspot!

If you do, it will be detected by `天翼校园客户端`, causing the network connection to drop.

To solve this problem, I recommend this small tool that runs on Windows.

I'm also writing it down so I don't forget 😂.

It needs to be used with the old version of `天翼校园客户端`.

There is currently no version for Android or iOS..

## Original usage tutorial

EShare Tool Preview

Version 1.1.1 (FR)

Unlimited sharing!

> Project URL: https://github.com/PandaAdap/EShareTool

### Note

This tool can only bypass the network-sharing restriction; it cannot bypass the one-account-one-device restriction.

It is intended for cases where multiple devices need to connect to the campus network.

### Requirements

The computer needs at least one wireless network adapter (to enable the hotspot).

If you don't have a wireless network adapter, you can search online for `无线网卡` and buy one!

In addition, another network adapter must already be connected to the campus network and able to access the internet successfully.

> Examples
>
> 1.  One wireless adapter is not connected to Wi-Fi, and another wired adapter is connected to the campus network
> 2.  One wireless adapter is not connected to Wi-Fi, and another wireless adapter is connected to the campus network
> 3.  Only one wireless adapter is connected to the campus network; enable the hotspot directly

### How to use

1. Uninstall the new version of the Tianyi Campus client, install the old version of the Tianyi Campus Network client included in the archive, and then launch the tool
2. Turn on the mobile hotspot (if it cannot be enabled, first log in to the campus network and get online, then turn it on)
3. Click Configure Sharing and you can turn on the mobile hotspot without disconnecting (if you logged in first, then turned on the hotspot, and then configured sharing, just log in again after configuration)
4. After configuration, sharing works permanently; no need to configure again, no need to keep this software running, and it still works after a restart!
5. If it doesn't work, try a few more times or leave a comment!
