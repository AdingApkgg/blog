## Preface

The moment this post goes live, it means I've officially moved from WordPress to Hexo!

Hexo is a static blog framework that can be deployed to free code hosting platforms.

That alone is an absolute advantage for me! It also settled which blog framework I should use.

After all, who doesn't love free stuff?

It took me over a month of tinkering, but Hexo is finally done, so WordPress can sit in the repo gathering dust.

To keep a record, I'll recommend the WordPress plugins I've used.

Just in case I come back to WordPress someday and forget all the plugins.

Below are some of the plugins and themes I was using on WordPress.

## Plugin Recommendations

### Live2DWebCanvas (Live2D Mascot)

Official description: Mascot plugin

![Live2DWebCanvas](/img/202302160744707.webp)

![Live2DWebCanvas](/img/202302160744025.webp)

First up is the Live2D mascot — practically a must-have for veterans!!!

Those who know, know...

But there are quite a few compatibility issues, so if you're worried about stability, consider it carefully...

> WordPress plugin link: https://cn.wordpress.org/plugins/live-2d/

### Akismet (Anti-Spam Comments)

Official description: Used by millions, Akismet is quite possibly **the best way in the world** to protect your site from spam comments. Your site is fully configured and gets uninterrupted protection.

![Akismet](/img/202302160752160.webp)

![Akismet](/img/202302160753195.webp)

As the name suggests, it's mainly used to fight spam comments and bot-generated junk. I can't really judge it...

After all, I abandoned WordPress not long after starting, so I never really experienced it.

If you've used it, feel free to leave a comment about your experience.

> WordPress plugin link: https://cn.wordpress.org/plugins/akismet/

### ProfilePress (Account Management)

Official description: The modern WordPress membership and user profile plugin.

Machine translation: A modern WordPress membership and user profile plugin.

![ProfilePress](/img/202302160802553.webp)

![ProfilePress](/img/202302160802875.webp)

This is...?

Seems to be some kind of account feature plugin, I forgot.

I remember it being useful, so I'll note it down for now.

> WordPress plugin link: https://cn.wordpress.org/plugins/wp-user-avatar/

### Redis Object Cache (Redis Object Cache)

Official description: A persistent object cache backend powered by Redis. Supports Predis, PhpRedis, Relay, replication, sentinels, clustering and WP-CLI.

Machine translation: A persistent object cache backend powered by Redis. Supports Predis, PhpRedis, Relay, replication, sentinels, clustering and WP-CLI.

![Redis Object Cache](/img/202302160808094.webp)

![Redis Object Cache](/img/202302160809995.webp)

Used to reduce load times and make refreshing feel smoother.

> WordPress plugin link: https://cn.wordpress.org/plugins/redis-cache/

### TablePress (Table Insertion)

Official description: Embed beautiful and feature-rich tables in your posts and pages without writing any code.

![TablePress](/img/202302160818120.webp)

![TablePress](/img/202302160818469.webp)

Lets you insert tables conveniently at any point while writing a post. Pretty handy.

> WordPress plugin link: https://cn.wordpress.org/plugins/tablepress/

### WordPress Importer

Official description: Import posts, pages, comments, custom fields, categories, tags and more from a WordPress export file.

![WordPress 导入工具](/img/202302160825457.webp)

![WordPress 导入工具](/img/202302160825976.webp)

Used for migrating the WordPress blog.

> WordPress plugin link: https://cn.wordpress.org/plugins/wordpress-importer/

### WP Mail SMTP

Official description: Reconfigure the `wp_mail()` functionality to use Gmail/Mailgun/SendGrid/SMTP instead of the default `mail()` and create an options page to manage settings.

![WP Mail SMTP](/img/202302160828691.webp)

![WP Mail SMTP](/img/202302160828458.webp)

For configuring comment reply emails.

Mainly used so that when someone replies after a comment, you get notified by email. Quite convenient.

> WordPress plugin link: https://cn.wordpress.org/plugins/wp-mail-smtp/

### WP-China-Yes (Speeding Up WordPress in China)

Official description: Connect your WordPress to the local ecosystem, which will give you a WordPress that better fits Chinese usage habits.

![WP-China-Yes](/img/202302160832939.webp)

It speeds up WordPress. Since WordPress is an overseas product, using it in China makes the admin dashboard rather laggy, so this plugin came about.

> Official plugin link: https://litepress.cn/

### Yoast SEO (Search Engine Optimization)

Official description: The first true all-in-one SEO solution for WordPress, including on-page content analysis, XML sitemaps and more.

![Yoast SEO](/img/202302160837833.webp)

![Yoast SEO](/img/202302160837359.webp)

This is a must-install plugin!

It improves your hit rate when users search for keywords and boosts indexing by search engines.

> WordPress plugin link: https://cn.wordpress.org/plugins/wordpress-seo/

### Health Check & Troubleshooting

Official description: Check the health of your WordPress installation.

![健康检查和故障排除](/img/202302160842281.webp)

![健康检查和故障排除](/img/202302160842124.webp)

Check the health status of WordPress at any time.

> WordPress plugin link: https://cn.wordpress.org/plugins/health-check/

### Small Tools

Official description: Quickly enable or disable some features.

![小工具](/img/202302160845946.webp)

We often need to add code to a theme's functions.php file to enable/disable certain WordPress features. Not only is that inconvenient, but you have to add it all over again after switching themes, so this little tool was written to toggle them with one click. (Shamelessly lifted from the official description because theirs is better written...)

> Official plugin link: https://gitee.com/beizigen/wordpress-smalltool

### Classic Widgets

Official description: Enables the classic widgets settings screens in Appearance → Widgets and the Customizer. Disables the block editor from managing widgets.

![经典小工具](/img/202302160849491.webp)

![经典小工具](/img/202302160849410.webp)

Lets you customize some widgets quickly. Pretty handy.

> WordPress plugin link: https://cn.wordpress.org/plugins/classic-widgets/

### Classic Editor

Official description: Enables the classic WordPress editor and the old-style Edit Post screen, including TinyMCE, Meta Boxes and more. Supports old plugins that extend this page.

![经典编辑器](/img/202302160853184.webp)

![经典编辑器](/img/202302160853203.webp)

WordPress's built-in post or page editor. Very classic.

> WordPress plugin link: https://cn.wordpress.org/plugins/classic-editor/

### WP Super Cache

Official description: A fast caching plugin for WordPress.

![超级缓存](/img/202302160856463.webp)

![超级缓存](/img/202302160855375.webp)

Improves overall loading speed

> WordPress plugin link: https://cn.wordpress.org/plugins/wp-super-cache/

GeneratePress places great emphasis on WordPress coding standards, so it is fully compatible with all well-coded plugins (including WooCommerce). GeneratePress is fully responsive, uses valid HTML/CSS, and has been translated into at least 25 languages by our enthusiastic user community. Learn more and check out our powerful premium version at https://generatepress.com.

![GeneratePress](https://www.wordtalk.com/wp-content/uploads/2021/02/about-GeneratePress.png)
