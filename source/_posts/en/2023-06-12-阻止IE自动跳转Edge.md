## Introduction

This article is only for those of you on Windows 10, since Windows 11 no longer has Internet Explorer.

Why would anyone still use IE these days? Obviously, because some websites only support IE—certain finance or government service sites, for instance—so you're left with no choice..

I'm well aware that IE is terrible and that there are plenty of alternatives, such as Chrome, Edge, and Firefox. But sometimes the choice isn't yours to make, and you have no choice but to use it.

Hence this tutorial, which solves the problem of IE automatically redirecting to Edge when opened on Windows 10. Please don't use IE unless you absolutely have to!

## Tutorial

### 0x0001

First, open the Edge browser and go to `设置` > `默认浏览器` > `Internet Explorer 兼容性`, then set `允许在 Internet Explorer 模式下重新加载网站 (IE 模式)` to `不允许`.

![](/img/202306122317010.webp)

### 0x0002

Press <kbd>Win</kbd> + <kbd>R</kbd>, type "regedit" and press <kbd>Enter</kbd> to open the Registry Editor.

Enter the following address into the address bar at the top of the Registry Editor, then press <kbd>Enter</kbd>.

```markdown
计算机\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Ext\CLSID
```

Change the string value whose data is `1` to `0`.

![](/img/202306122319584.webp)

### 0x0003

Open IE. If it doesn't redirect to Edge, it worked!

If it still redirects, some other unwanted software may be redirecting IE—try uninstalling and cleaning it up, then try again.
