Recently, while using the Hugo framework—without a ready-made theme—to hand-build some curious "[小](https://vns.saop.cc/)" website, I found that when using the busuanzi counter together with the swup page transition library to switch pages, the counter data sometimes fails to display. After sending the code in the busuanzi `busuanzi.pure.mini.js` to an AI for analysis, I discovered that the data can be refreshed by manually calling `bszCaller.fetch()`. So here I'll note down how to manually reload the busuanzi counter.

```js
bszCaller.fetch(
  "//busuanzi.ibruce.info/busuanzi?jsonpCallback=BusuanziCallback",
  function (a) {
    bszTag.texts(a);
    bszTag.shows();
  }
);
```
