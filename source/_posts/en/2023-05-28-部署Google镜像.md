{% note info simple %}

- This tutorial uses the [gaowanlu/google](https://github.com/gaowanlu/google) open-source project on GitHub to build your own serverless Google search mirror.
- This article is mainly aimed at those without a server. If you do have a server, you can deploy it with Docker containers—see the project's open-source documentation for details.
- Benefits of self-hosting: you can access it without a VPN, it's fast, and the flex factor is MAX.
- Demo site: [google.saop.cc](https://google.saop.cc/)

{% endnote %}

## Prerequisites

1. Register a [GitHub](https://github.com) account (skip this if you already have one).
2. Register a [Vercel](https://vercel.com) account (skip this if you already have one).
3. Have a tool that can access GitHub and the Vercel website (a VPN).
4. Your own domain and some basic computer knowledge.
5. A pair of hands, a brain, a pair of eyes, and a computer or phone.

## Tutorial

### 0x0001

Go to the repository of the [gaowanlu/google](https://github.com/gaowanlu/google) open-source project, click the `Fork` button in the upper right corner to fork the repository's main branch,

then go to the [Vercel](https://vercel.com/) platform and click `Add New...` > `Project`. Use your brain and add the repository you just forked.

### 0x0002

Once deployment succeeds, go to the project's `Settings` > `Domains` custom domains and add your own subdomain—like mine, `google.saop.cc`.

Go to your domain's DNS provider (for example, Tencent Cloud for my domain) and add the CNAME record provided by Vercel.

### 0x0003

Wait a bit—about two or three minutes—then visit the subdomain you just bound.

Try searching for something random, like `Hello World`..

![](/img/202306211411957.webp)

![](/img/202306211411405.webp)

Generally, it should work and be searchable right after you visit it. If an error appears, start over from the beginning—usually it's a mistake in your own operation.

## Pros and Cons

### Pros

You can find some things that can't be searched domestically.

For example, all those lewd websites—generally, the search engines that work in China block them, such as `必应`, `百度`, `搜狗`, etc.

It's sometimes a bit faster than accessing through a VPN, because the VPN process involves encryption and decryption, which always takes a little time.

### Cons

You'll find that some of the websites in the search results can't be opened when you click them.

This is because the mirror site only accelerates Google search, not all websites globally.

So some blocked foreign websites won't open, such as [Pornhub](https://pornhub.com/).

If you use a VPN, you can access them normally.
