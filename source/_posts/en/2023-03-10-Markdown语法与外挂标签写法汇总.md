## Blockquote note

{% tabs 分栏 %}

<!-- tab 通用配置 -->

```Markdown
note:
  # Note tag style values:
  #  - simple    bs-callout old alert style. Default.
  #  - modern    bs-callout new (v2-v3) alert style.
  #  - flat      flat callout style with background, like on Mozilla or StackOverflow.
  #  - disabled  disable all CSS styles import of note tag.
  style: flat
  icons: true
  border_radius: 3
  # Offset lighter of background in % for modern and flat styles (modern: -12 | 12; flat: -18 | 6).
  # Offset also applied to label tag variables. This option can work with disabled note tag.
  light_bg_offset: 0
```

<!-- endtab -->

<!-- tab 语法格式 -->

```Markdown
# 自带icon
{% note [class] [no-icon] [style] %}
Any content (support inline tags too.io).
{% endnote %}
# 外部icon
{% note [color] [icon] [style] %}
Any content (support inline tags too.io).
{% endnote %}
```

<!-- endtab -->

<!-- tab 参数配置 -->

1. Built-in icon

| Parameter | Usage |
| ------- | :---: |
| class   | [Optional] Identifier; different identifiers come with different color schemes ( default / primary / success / info / warning / danger ) |
| no-icon | [Optional] Do not display the icon |
| style   | [Optional] Overrides the style set in the config (simple/modern/flat/disabled) |

2. External icon

| Parameter | Usage |
| ------- | :----------------------------------------------------------------------------------------------: |
| class   | [Optional] Identifier; different identifiers produce different color schemes ( default / blue / pink / red / purple / orange / green ) |
| no-icon | [Optional] Custom icon can be configured (only FontAwesome icons are supported, or set no-icon ) |
| style   | [Optional] Overrides the style set in the config (simple/modern/flat/disabled) |

<!-- endtab -->

## Gallery gallery

{% tabs 分栏 %}

<!-- tab 标签语法 -->

1. gallerygroup album gallery

```Markdown
{% galleryGroup name description link img-url %}
{% galleryGroup name description link img-url %}
{% galleryGroup name description link img-url %}
</div>
```

2. gallery album

```Markdown
{% gallery %}
markdown 圖片格式
{% endgallery %}
```

<!-- endtab -->

<!-- tab 参数配置 -->

- gallerygroup photo gallery

| Parameter   | Description                          |
| ----------- | ------------------------------------ |
| name        | Gallery name                         |
| description | Gallery description                  |
| link        | URL linking to the corresponding album |
| img-url     | Gallery cover                        |

- gallery album

  Unlike the old Gallery album, the new Gallery album automatically arranges the layout according to image length, and is also more convenient to write, just like the markdown format. You can insert it into the corresponding md as needed. No need to configure width and height yourself anymore. **It is recommended to deliberately use images of different lengths, sizes, and orientations when pasting**, which will produce better results. (Images of exactly the same size will only be tiled, and the result is terrible.)

## Column tabs

{% tabs 分栏 %}

<!-- tab 标签语法 -->

```markdown
{% tabs Unique name, [index] %}

<!-- tab [Tab caption] [@icon] -->

Any content (support inline tags too).

<!-- endtab -->

{% endtabs %}
```

<!-- endtab -->

<!-- tab 配置参数 -->

1. Unique name :

   - The unique name of the tab block label, without commas.

   - Used in the #id as the prefix for each tab and its index number.

   - If the name contains spaces, all spaces will be replaced by dashes when generating the #id.

   - It only needs to be unique within the current post/page URL!

2. [index]:

   - The index number of the active tab.

   - If not specified, the first tab (1) will be selected.

   - If index is -1, no tab will be selected.

   - Optional parameter.

3. [Tab caption]:

   - The caption of the current tab.

   - If no caption is specified, the unique name with a tab index suffix will be used as the tab caption.

   - If no caption is specified but an icon is, the caption will be empty.

   - Optional parameter.

4. [@icon]:

   - FontAwesome icon name (full name, looks like "fas fa-font")

   - Can be specified with or without a space;

   - For example, 'Tab caption @icon' and 'Tab caption@icon'.

   - Optional parameter.

<!-- endtab -->

## Hidden Block

{% tabs 分栏 %}

<!-- tab 标签语法 -->

```markdown
{% hideBlock display,bg,color %}
content
{% endhideBlock %}
```

<!-- endtab -->

<!-- tab 参数配置 -->

1. content: the content to be hidden
2. display: the text shown on the button before it is revealed (optional)
3. bg: the background color of the button (optional)
4. color: the color of the text on the button (optional)

<!-- endtab -->

<!-- tab 示例源码 -->

```markdown
{% hideBlock 点我预览, blue %}
这里有张图片：
<img src="https://registry.npmmirror.com/js-asuna/latest/files/pic/Asuna/Asuna16x9.webp" alt="Asuna" />
{% endhideBlock %}
```
