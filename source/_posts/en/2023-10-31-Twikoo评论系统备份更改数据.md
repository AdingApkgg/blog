## Exporting Comment Data

### Method 1

You can go to the `管理面板` of the comments in `Twikoo`, select the `导出` tab, and click the `导出评论` button to export Twikoo's comment data into a `json` file.

![](/img/202310312344559.webp)

### Method 2 (Recommended)

Export the comment data of `Twikoo` into a `json` file. For details, see the following article:

>[Twikoo 评论数据导出教程 - iMaeGoo's Blog](https://www.imaegoo.com/2022/twikoo-data-export/)

## Restoring Comment Data

If you only want to back up the data and have no other needs, you're done at this step. To restore comment data later, simply select the `导入` tab, choose the source system `Twikoo（JSON）`, select the backup file you exported, and click `开始导入`. If you also need to modify the comment data, keep reading.

## Editing Comment Data

You can open the `Twikoo` comment data file with the `.json` extension using `Visual Studio Code` or another `IDE` to edit the comment data you see. You can refer to the table below for the meaning of common fields when making changes:

|   Value   |              Meaning              |
| :-----: | :--------------------------: |
|  nick   |             Nickname             |
|  mail   |              Email              |
| mailMd5 |          Email MD5 value          |
|  link   |           Website link           |
|   ua    |       Device user agent code      |
|   ip    |            IP address            |
| master  |  Whether the commenter is the site owner  |
|   url   |     Relative path from the homepage     |
|  href   | Absolute path of the current location when the comment was sent |
| comment |          Comment content          |
| isSpam  |          Whether it is spam         |
| created |         Creation timestamp         |
| updated |         Update timestamp         |
| avatar  |           Avatar link            |
|   top   |          Whether it is pinned          |

![](/img/202310312305132.webp)

After editing, go to the database of your `Twikoo` comments—for example, my `MongoDB Cloud`—and delete the `comment` item.

![](/img/202310312351050.webp)

Of course, you can use a better method as long as the `comment` item is eventually deleted...

Once you've finished deleting, follow the above **Restoring Comment Data** steps and the modification is complete.
