## 1. Install Increment Selection

Search for Increment Selection in the VS Code extensions marketplace and install it.

![Increment Selection](/img/202304082310419.webp)

## Incrementing and decrementing numbers

### Incrementing numbers

#### Shortcut sequence (increment from zero)

<kbd>Shift</kbd> + <kbd>Alt</kbd> to select multiple lines

<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>i</kbd>

#### Shortcut sequence (increment starting from any number)

<kbd>Shift</kbd> + <kbd>Alt</kbd> to select multiple lines

Type any number, then <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>→</kbd> to select the number

<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>i</kbd>

### Decrementing numbers

The same as incrementing numbers, except that you select from the bottom up.

## Incrementing and decrementing letters

The same as incrementing and decrementing numbers; just type the letters in advance.
