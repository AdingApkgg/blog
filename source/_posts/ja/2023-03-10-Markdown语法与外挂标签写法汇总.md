{% note info %}この部分は安知魚を参照：[安知鱼主题标签 Tag Plugins](https://blog.anheyu.com/posts/d50a.html){% endnote %}

## 引用 note

{% tabs 分栏 %}

<!-- tab 通用配置 -->

```Markdown
note:
  # Note tag style values:
  #  - simple    bs-callout old alert style. Default.
  #  - modern    bs-callout new (v2-v3) alert style.
  #  - flat      flat callout style with background, like on Mozilla or StackOverflow.
  #  - disabled  disable all CSS styles import of note tag.
  style: flat
  icons: true
  border_radius: 3
  # Offset lighter of background in % for modern and flat styles (modern: -12 | 12; flat: -18 | 6).
  # Offset also applied to label tag variables. This option can work with disabled note tag.
  light_bg_offset: 0
```

<!-- endtab -->

<!-- tab 语法格式 -->

```Markdown
# 自带icon
{% note [class] [no-icon] [style] %}
Any content (support inline tags too.io).
{% endnote %}
# 外部icon
{% note [color] [icon] [style] %}
Any content (support inline tags too.io).
{% endnote %}
```

<!-- endtab -->

<!-- tab 参数配置 -->

1. 内蔵 icon

| パラメータ |                                               使い方                                               |
| ------- | :----------------------------------------------------------------------------------------------: |
| class   | 【任意】識別子。識別子ごとに異なる配色になります （ default / primary / success / info / warning / danger ） |
| no-icon |                                      【任意】icon を表示しない                                        |
| style   |                  【任意】設定内の style を上書きできます （simple/modern/flat/disabled）                  |

2. 外部 icon

| パラメータ |                                               使い方                                               |
| ------- | :----------------------------------------------------------------------------------------------: |
| class   | 【オプション】識別子。識別子ごとに異なる配色になります（ default / blue / pink / red / purple / orange / green ） |
| no-icon |             【オプション】カスタム icon を設定できます（fontawesome アイコンのみ対応、no-icon の設定も可能）             |
| style   |                  【オプション】設定内の style を上書きできます（simple/modern/flat/disabled）                  |

<!-- endtab -->

## タイムライン timeline

{% tabs 分栏 %}

<!-- tab 标签语法 -->

```Markdown
{% timeline 时间线标题（可选）[,color] %}
<!-- timeline 时间节点（标题） -->
正文内容
<!-- endtimeline -->
<!-- timeline 时间节点（标题） -->
正文内容
<!-- endtimeline -->
{% endtimeline %}
```

<!-- endtab -->

<!-- tab 配置参数 -->

1. `title`：タイトル／タイムライン
2. `color`：`timeline` 色：default（空欄）/ blue / pink / red / purple / orange / green
   <!-- endtab -->

```Markdown

3. 2.x 版本的 fancybox 标签在 3.x 版本中被重命名为 gallery 。
4. 2.x 版本的置顶 `top: true` 改为了 `pin: true`，并且同样适用于 `layout: page` 的页面。
5. 如果使用了 `hexo-offline` 插件，建议卸载，3.0 版本默认开启了 pjax 服务。

1. 全局搜索 `seotitle` 并替换为 `seo_title`。
2. group 组件的索引规则有变，使用 group 组件的文章内，`group: group_name` 对应的组件名必须是 `group_name`。
```

## 段組み tab

{% tabs 分栏 %}

<!-- tab 标签语法 -->

```markdown
{% tabs Unique name, [index] %}

<!-- tab [Tab caption] [@icon] -->

Any content (support inline tags too).

<!-- endtab -->

{% endtabs %}
```

<!-- endtab -->

<!-- tab 配置参数 -->

1. 一意の名前：

   - タブブロックの一意の名前です。カンマは含めません。

   - 各タブとそのインデックス番号のプレフィックスとして #id で使用されます。

   - 名前にスペースが含まれる場合、#id の生成時にはすべてのスペースがダッシュに置き換えられます。

   - 現在の投稿／ページの URL 内でのみ一意である必要があります！

2. [index]：

   - アクティブなタブのインデックス番号です。

   - 指定しない場合は最初のタブ（1）が選択されます。

   - index が -1 の場合、どのタブも選択されません。

   - 省略可能なパラメータです。

3. [Tab caption]：

   - 現在のタブのタイトルです。

   - タイトルを指定しない場合、タブインデックスのサフィックスが付いた一意の名前がタブのタイトルとして使用されます。

   - タイトルを指定せず、アイコンのみを指定した場合はタイトルが空になります。

   - 省略可能なパラメータです。

4. [@icon]：

   - FontAwesome のアイコン名（完全な名前で、「fas fa-font」のような形式）。

   - スペースあり・なしのどちらでも指定できます。

   - 例えば「Tab caption @icon」と「Tab caption@icon」。

   - 省略可能なパラメータです。
