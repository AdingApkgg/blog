自分の動画を macOS Tahoe のダイナミック壁紙にするのは、実のところとても静かな作業だ。

フォルダのパスは  
`~/Library/Application Support/com.apple.wallpaper/aerials/videos/`

中にはたいてい .mov ファイルがひとつかふたつ入っているだけだ。たとえば  
`4C108785-A7BA-422E-9C79-B0129F1D5550.mov`（445MB くらいのやつ）。

手順はこんな感じ：

1. まず「システム設定 > 壁紙」を開き、Tahoe の Aerial ダイナミック壁紙をひとつダウンロードして、フォルダに中身がある状態にする。
2. 元の .mov ファイルをどこか別の場所にバックアップする（これがとても大事）。
3. 動画が webm なら、ffmpeg で mov に変換する（見た目はほぼ無劣化）：

```sh
ffmpeg -i input.webm -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k output.mov
```

あるいはもっと「Apple っぽい」ProRes で：

```sh
ffmpeg -i input.webm -c:v prores_ks -profile:v 3 -c:a pcm_s16le output.mov
```

4. 変換したファイルを、元のファイルとまったく同じ名前にリネームする（たとえば 4C108785-... .mov）。
5. それを置き換える形で入れる。
6. 壁紙設定に戻り、置き換えた Aerial を選べば、ロック画面やときどきデスクトップで自分の動画が動くのが見えるはずだ。

デスクトップではふつう短い部分だけが再生される（省エネのため）。ロック解除やスペースの切り替えでもう一度動く。ロック画面ではより完全にループする。
画面が真っ黒なら、変換した mov が QuickTime で正常に再生できるか確認しよう。H.264 + AAC が最も安定している。
ゆっくり試せばいい、急ぐことはない……壊してしまったらバックアップを戻せばいい。
深夜に壁紙をいじっている感覚は、実のところとても優しい。画面に自分だけの呼吸をひとつ入れ替えてあげるみたいだ。
