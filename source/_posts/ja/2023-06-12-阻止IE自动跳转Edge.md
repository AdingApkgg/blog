## はじめに

この記事は Windows 10 システムをお使いの方のみ参考にしてください。Windows 11 にはすでに IE ブラウザが存在しないからです。

今さらなぜ IE を使うのか？明らかに、一部の Web サイトは IE しかサポートしていないからです。たとえば金融系や政府の手続き系の一部などがそうで、そうなると使わざるを得ません…

もちろん IE が使いにくいことは承知していますし、Chrome や Edge、Firefox といった代替品もたくさんあります。しかし選択権が自分の手にないときは、使わざるを得ないのです。

というわけで、このチュートリアル記事です。Win10 システムで IE ブラウザを開くと自動的に Edge にジャンプしてしまう問題を解決します。必要でない限り IE ブラウザは使わないでください！

## チュートリアル

### 0x0001

まず Edge ブラウザを開き、`设置`>`默认浏览器`>`Internet Explorer 兼容性` に進み、`允许在 Internet Explorer 模式下重新加载网站 (IE 模式)` を `不允许` に設定します。

![](/img/202306122317010.webp)

### 0x0002

<kbd>Win</kbd> + <kbd>R</kbd> を押し、「regedit」と入力して <kbd>Enter</kbd> でレジストリエディターを開きます。

以下のアドレスをレジストリエディター上部のアドレスバーに入力し、<kbd>Enter</kbd> を押します。

```markdown
计算机\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Ext\CLSID
```

値が `1` である文字列値を `0` に変更します。

![](/img/202306122319584.webp)

### 0x0003

IE ブラウザを開いて、Edge にジャンプしなければ成功です！

それでもジャンプする場合は、他にも IE をリダイレクトする迷惑ソフトが残っている可能性があります。アンインストールしてクリーンアップしてから、もう一度試してみてください。
