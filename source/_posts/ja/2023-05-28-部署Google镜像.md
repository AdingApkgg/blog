{% note info simple %}

- 本チュートリアルでは GitHub 上の[gaowanlu/google](https://github.com/gaowanlu/google)オープンソースプロジェクトを利用して、サーバーレスで自分だけの Google 検索ミラーを構築します
- この記事は主にサーバーを持っていない方向けの解説です。サーバーをお持ちの場合は Docker コンテナ化によるデプロイが可能で、詳細は該当プロジェクトのオープンソースドキュメントを参照してください
- 自前構築のメリット：魔法を使わずにアクセスできる、速度が比較的速い、ドヤ顔効果 MAX
- デモサイト：[google.saop.cc](https://google.saop.cc/)

{% endnote %}

## 前提条件

1. [GitHub](https://github.com)アカウントを登録する（すでにお持ちの場合は不要）
2. [Vercel](https://vercel.com)アカウントを登録する（すでにお持ちの場合は不要）
3. GitHub と Vercel の公式サイトにアクセスできるツール（魔法）があること
4. 自分専用のドメインと、一定のコンピュータ基礎知識
5. 両手、頭脳、両目、そしてパソコンかスマホが1台

## チュートリアル

### 0x0001

[gaowanlu/google](https://github.com/gaowanlu/google)オープンソースプロジェクトのリポジトリへ移動し、右上の`Fork`ボタンをクリックしてこのリポジトリの main ブランチを Fork します。

[Vercel](https://vercel.com/)プラットフォームへ移動して`Add New...`>`Project`をクリックし、自分の頭を少々働かせて、先ほど Fork したリポジトリを追加します。

### 0x0002

デプロイが成功したら、プロジェクトの`Settings`>`Domains`のカスタムドメインへ進み、自分のサブドメインを追加します。たとえば私の場合は`google.saop.cc`です。

自分のドメインの DNS サービスプロバイダー（たとえば私のドメインなら Tencent Cloud）へ移動し、Vercel が提供する CNAME レコードを追加します。

### 0x0003

しばらく待ちます。だいたい2〜3分ほどで、先ほどバインドしたサブドメインにアクセスしてみましょう。

適当に何かを検索してみてください。たとえば`Hello World`など..

![](/img/202306211411957.webp)

![](/img/202306211411405.webp)

基本的にはそのままアクセスして問題なく検索できるはずです。もしエラーが出たら最初からやり直してください。たいていは自分の操作ミスが原因です。

## メリットとデメリット

### メリット

国内では検索できないようないくつかのものが検索できます。

たとえば大量のえっちなサイトなど。国内で使える検索エンジンの多くはブロックしています。たとえば`必应`、`百度`、`搜狗`など..

魔法を使ったアクセスに比べて少し速いことがあります。なぜなら魔法の過程では暗号化と復号化が必要で、どうしても少し時間がかかるからです。

### デメリット

検索結果に出てくる一部のサイトは、クリックしても開けないことに気づくでしょう。

これはミラーサイトが Google 検索だけを高速化しているのであって、すべてのサイトをグローバルに高速化しているわけではないからです。

そのため、ブロックされている一部の海外サイトは開けません。たとえば[Pornhub](https://pornhub.com/)です。

魔法を使えば、正常にアクセスできます。
