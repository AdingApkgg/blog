[Hexo](https://hexo.io/) へようこそ！これがあなたの最初の投稿です。詳しくは [documentation](https://hexo.io/docs/) をご覧ください。Hexo の使用中に問題が発生した場合は、[troubleshooting](https://hexo.io/docs/troubleshooting.html) に回答があります。または [GitHub](https://github.com/hexojs/hexo/issues) で私に質問することもできます。

## クイックスタート

### 新しい投稿を作成する

```bash
$ hexo new "My New Post"
```

詳細：[Writing](https://hexo.io/docs/writing.html)

### サーバーを起動する

```bash
$ hexo server
```

詳細：[Server](https://hexo.io/docs/server.html)

### 静的ファイルを生成する

```bash
$ hexo generate
```

詳細：[Generating](https://hexo.io/docs/generating.html)

### リモートサイトへデプロイする

```bash
$ hexo deploy
```

詳細：[Deployment](https://hexo.io/docs/one-command-deployment.html)
