## 説明

> ここでは原神私服に関する各種よくある問題の解決方法をまとめています
>
> それでも問題が解決しない場合は、コメント欄からフィードバックをお寄せください

## 問題と解決法

{% hideToggle 4212、4214错误, blue %}

ケース1：パッチが当たっていない、または間違って当てている場合は、ご自身で確認してください

ケース2：私服の`游戏版本`が古すぎます。更新してください

{% endhideToggle %}

{% hideToggle 进门后显示连接超时, cyan %}

おそらく`服务器`が攻撃されたかサービス停止しています。前者ならしばらく待ってから接続し、後者なら`服务器`を変更してください

{% endhideToggle %}

{% hideToggle 进门后白屏, green %}

ケース1：おそらく`服务器`が攻撃されたかサービス停止しています。前者ならしばらく待ってから接続し、後者なら`服务器`を変更してください

ケース2：アカウントが死んでいるので、別のアカウント名で入り直してください

{% endhideToggle %}

{% hideToggle 4206错误, yellow %}

`服务器`の問題かもしれません。サーバーの変更をおすすめします

{% endhideToggle %}

{% hideToggle 登录账号提示网络错误/网络超时, red %}

`服务器`の問題かもしれません。サーバーの変更をおすすめします

{% endhideToggle %}

{% hideToggle 点击登录转圈然后没反应, blue %}

全部削除してもう一度やり直してください。1回でダメなら2回です！

{% endhideToggle %}

{% hideToggle 开启代理后还是登的官服, cyan %}

Win7 は古すぎる可能性があります。Win10 にアップグレードしてください

そうでない場合は、すべてのアンチウイルスソフトを無効化またはアンインストールしてください

その後、全部削除してもう一度やり直してください。1回でダメなら2回です！

{% endhideToggle %}

{% hideToggle 4201、-9203错误, green %}

Win7 は古すぎる可能性があります。Win10 にアップグレードしてください

そうでない場合は、すべてのアンチウイルスソフトを無効化またはアンインストールしてください

その後、全部削除してもう一度やり直してください。1回でダメなら2回です

{% endhideToggle %}

{% hideToggle 卡检查更新, yellow %}

全部削除してもう一度やり直してください。1回でダメなら2回、それでもダメならスマホを変えてください

{% endhideToggle %}

{% hideToggle 进入 SF 服务器后 “准备加载数据” 卡 “45%”, red %}

原因はリソースが完全にダウンロードされていないことです

{% endhideToggle %}

{% hideToggle 为什么不能回血, blue %}

ケース1：サーバーの問題です。別のサーバーに変えてください

ケース2：現在の私服バージョンの問題である可能性もあります。仕様と言えます

コマンド`/h`で全員のHPを一括回復すれば大丈夫です

{% endhideToggle %}

{% hideToggle Win7系统代理工具兼容性问题, cyan %}

Win7 でプロキシソフトが非対応の場合は、米哈游代理转向を試してみてください（ネットディスク内にあります）

{% endhideToggle %}

{% hideToggle 服务器繁忙，请稍后再试(502), green %}

サーバーが攻撃された可能性があります。しばらくしてからゲームに接続するか、別のサーバーを試してみてください...

{% endhideToggle %}

{% hideToggle 指令怎么用，在哪用？, yellow %}

作成したばかりの新規アカウントには、フレンドリストに必ず1人フレンドがいます。

{% note info %}

フレンドがいない場合は、おそらく肝服なので、指令服に変更してください

{% endnote %}

あとは必要なコマンドを送るだけです

{% endhideToggle %}

{% hideToggle 指令用不了, red %}

プレイしているサーバーが特殊で、一部のコマンドの使い方が標準と異なる可能性があります。

現在のサーバー専用のコマンドやコマンドジェネレーターを探すか、

指令標準に従っている他のサーバーに変更してください

{% endhideToggle %}

{% hideToggle 二级地址解析失败, blue %}

おそらくサーバーがメンテナンス中か、運営が逃げたのでしょう。しばらくしてから接続してください

{% endhideToggle %}
