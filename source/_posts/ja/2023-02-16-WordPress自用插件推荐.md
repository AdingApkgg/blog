## はじめに

この記事を公開した時点で、WordPress から Hexo へ正式に移行したことになります！

Hexo は静的ブログフレームワークで、無料のコードホスティングプラットフォームにデプロイできます。

この点だけでも私にとっては間違いなく大きなメリットです！どのブログフレームワークを使うべきかも示してくれました。

なにしろ無料は誰だって好きですからね。

1か月以上も試行錯誤してようやく Hexo の作業が終わり、WordPress はリポジトリに置いてホコリをかぶるだけになりました。

記録として、私が使ってきた WordPress プラグインをいくつか紹介しておきます。

将来また WordPress を使うことに戻るかもしれないので、そのときにプラグインを忘れてしまわないように。

以下、私の WordPress で使っていたプラグインとテーマをいくつか紹介します。

## プラグインのおすすめ

### Live2DWebCanvas（Live2d 看板娘）

公式説明：看板娘プラグイン

![Live2DWebCanvas](/img/202302160744707.webp)

![Live2DWebCanvas](/img/202302160744025.webp)

まずは Live2d 看板娘、もはや古参ユーザー必須と言えるでしょう！！！

詳しくはわかる人にはわかるということで。。

ただ互換性の問題がかなり多いので、不安定さが心配なら状況に応じて検討してもよいかもしれません...

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/live-2d/

### Akismet（スパムコメント対策）

公式説明：何百万人もの人々に使用されている Akismet は、**世界で最も優れたスパムコメントからあなたのサイトを保護する方法**かもしれません。あなたのサイトは完全に設定され、途切れることのない保護を受けられます。

![Akismet](/img/202302160752160.webp)

![Akismet](/img/202302160753195.webp)

名前のとおり、主にスパムコメントやスパム目的の投稿に対抗するためのものです。私には評価しにくいですが...

なにしろ WordPress は使い始めて間もなく廃止してしまったので、あまり体験していません。

使ったことがある人はコメントで感想を教えてください。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/akismet/

### ProfilePress（アカウント管理）

公式説明：The modern WordPress membership and user profile plugin.

機械翻訳：モダンな WordPress メンバーシップおよびユーザープロフィールプラグイン。

![ProfilePress](/img/202302160802553.webp)

![ProfilePress](/img/202302160802875.webp)

これは。。？

アカウント機能系のプラグインだったような、忘れました。

たぶん使っていたはずなので、とりあえず記録しておきます。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/wp-user-avatar/

### Redis Object Cache（Redis オブジェクトキャッシュ）

公式説明：A persistent object cache backend powered by Redis. Supports Predis, PhpRedis, Relay, replication, sentinels, clustering and WP-CLI.

機械翻訳：Redis によって支えられた永続的なオブジェクトキャッシュバックエンド。Predis、PhpRedis、リレー、レプリケーション、センチネル、クラスタリング、WP-CLI をサポートします。

![Redis Object Cache](/img/202302160808094.webp)

![Redis Object Cache](/img/202302160809995.webp)

読み込み速度を下げるためのもので、更新のスムーズさを向上させます。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/redis-cache/

### TablePress（表の挿入）

公式説明：コードを一切書かずに、美しく機能豊富な表を記事やページに埋め込むことができます。

![TablePress](/img/202302160818120.webp)

![TablePress](/img/202302160818469.webp)

記事を書いている途中でいつでも手軽に表を挿入できるので、なかなか便利です。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/tablepress/

### WordPress インポートツール

公式説明：WordPress のエクスポートファイルから投稿、ページ、コメント、カスタムフィールド、カテゴリー、タグなど更多の内容をインポートします。

![WordPress 导入工具](/img/202302160825457.webp)

![WordPress 导入工具](/img/202302160825976.webp)

WordPress ブログの移行に使うものです。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/wordpress-importer/

### WP Mail SMTP

公式説明：`wp_mail()`機能を再設定して、デフォルトの`mail()`ではなく Gmail/Mailgun/SendGrid/SMTP を使用できるようにし、設定を管理するためのオプションページを作成します。

![WP Mail SMTP](/img/202302160828691.webp)

![WP Mail SMTP](/img/202302160828458.webp)

コメント後のメール返信機能を設定するものです。

主に、コメントした後に誰かが返信するとメールで通知されるようにするためのもので、なかなか便利です。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/wp-mail-smtp/

### WP-China-Yes（国内の WP を高速化）

公式説明：あなたの WordPress をローカルエコシステムに接続します。これにより、中国人の使用習慣に寄り添った WordPress が手に入ります。

![WP-China-Yes](/img/202302160832939.webp)

WordPress を高速化できます。WordPress は海外製なので、

国内で使うと管理画面の体験がかなり重くなります。

そこでこのプラグインが生まれました。

> プラグイン公式リンク：https://litepress.cn/

### Yoast SEO（検索エンジン最適化）

公式説明：真の意味で初の WordPress オールインワン SEO ソリューション！ページコンテンツ分析、XML サイトマップなど多くの機能を備えています。

![Yoast SEO](/img/202302160837833.webp)

![Yoast SEO](/img/202302160837359.webp)

これは必須のプラグインです！

ユーザーがキーワードで検索したときのヒット率を高め、検索エンジンへのインデックスを促進します。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/wordpress-seo/

### サイトヘルスチェックとトラブルシューティング

### 小ツール

公式説明：いくつかの機能をすばやくオン・オフできます。

![小工具](/img/202302160845946.webp)

テーマの functions.php ファイルにコードを追加して WordPress の機能をオン・オフする必要がよくありますが、コードを追加するのは非常に面倒なうえ、テーマを変更するとまた追加し直さなければなりません。そこでこの小ツールを書いてワンクリックでオン・オフできるようにしました。（公式のほうがよく書けていると思ったのでそのまま持ってきたやつです...）

> プラグイン公式リンク：https://gitee.com/beizigen/wordpress-smalltool

### クラシックウィジェット

公式説明：外観-ウィジェットおよびカスタマイザーでクラシックウィジェット設定ページを有効にし、ブロックエディターでウィジェットを管理することを禁止します。

![经典小工具](/img/202302160849491.webp)

![经典小工具](/img/202302160849410.webp)

いくつかのウィジェットをすばやくカスタマイズできるので、なかなか便利です。

> WordPress プラグインリンク：https://cn.wordpress.org/plugins/classic-widgets/

### クラシックエディター

公式説明：TinyMCE、Meta Boxes などを含む WordPress クラシックエディターおよび旧式の投稿編集ページを有効にします。このページを拡張する旧プラグインをサポートします。

![经典编辑器](/img/202302160853184.webp)

![经典编辑器](/img/202302160853203.webp)

WordPress 標準の投稿・ページエディターで、とてもクラシックです。

![超级缓存](/img/202302160856463.webp)

![超级缓存](/img/202302160855375.webp)

![Argon](/img/202302160859147.webp)

私が WordPress で使っているテーマ

確かにかなりシンプルなテーマです

> テーマの GitHub リンク：https://github.com/solstice23/argon-theme
>
> テーマ公式デモサイト：https://solstice23.top/

### GeneratePress

公式説明：GeneratePress は速度と使いやすさを重視した軽量な WordPress テーマです。 パフォーマンスを最重要視しており、新規インストールした GeneratePress が追加するページサイズはわずか 10kb 未満です（gzip 圧縮を有効にした場合）。 ブロックエディター（Gutenberg）を最大限に活用し、作成するコンテンツをより直感的にコントロールできるようにしています。 ページビルダーを使用している場合でも、GeneratePress はご要望に完全に応えるテーマです。GeneratePress は Beaver Builder や Elementor を含む一般的なページビルダーと完全に互換性があります。 GeneratePress は WordPress のコーディング標準を非常に重視しているため、適切にコーディングされたすべてのプラグイン（WooCommerce を含む）と完全に互換性があります。 GeneratePress は完全にレスポンシブで、有効な HTML/CSS を使用しており、熱心なユーザーコミュニティによって少なくとも 25 の言語に翻訳されています。GeneratePress の数多くの特徴は以下のとおりです： 60 以上のカラーコントロール、強力な動的タイポグラフィシステム、5 つのナビゲーション位置、5 つのサイドバーレイアウト、ドロップダウンメニュー（クリックまたはホバー）、そして 9 つのウィジェットエリア。 詳細と強力なプレミアム版については https://generatepress.com をご覧ください。

![GeneratePress](https://www.wordtalk.com/wp-content/uploads/2021/02/about-GeneratePress.png)

WordPress の人気テーマの一つで、カスタマイズの自由度が非常に高いのですが、

デフォルトの見た目はかなり素朴なので、ある程度時間をかけて調整する必要があります

> テーマ公式サイト：https://generatepress.com/

### Astra

公式説明：Astra は高速でカスタマイズ可能な美しいテーマで、ブログ、個人のポートフォリオ、ビジネスサイト、WooCommerce ストアに適しています。 非常に軽量（フロントエンドは 50KB 未満）で、あなたのサイトに比類のない速度をもたらします。 Astra は SEO のために生まれ、Schema.org のコードを統合しているので、検索エンジンがあなたのサイトを好むようになります。 すべてのページビルダー（Elementor、Beaver Builder、Visual Composer、SiteOrigin、Divi など）と完璧に連携できる特別な機能とテンプレートを提供しています。その他の特徴としては：＃WooCommerce 対応 ＃レスポンシブデザイン ＃RTL と翻訳に対応 ＃プレミアムプラグインで拡張可能 ＃定期的なアップデート ＃Brainstorm Force による設計、開発、保守、サポート。完璧なベーステーマをお探しですか？もう考える必要はありません。Astra という高速でカスタマイズ可能、WooCommerce 対応のテーマを使って、あらゆる種類のサイトを構築できます！

![Astra](https://i0.wp.com/themes.svn.wordpress.org/astra/4.6.5/screenshot.jpg)

WordPress の人気テーマの一つで、華やかな外観が最初から備わっていて、なかなか良い感じです

> テーマ公式サイト：https://wpastra.com/
