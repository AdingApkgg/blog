## コメントデータのエクスポート

### 方法1

`Twikoo`のコメントの`管理面板`から`导出`タブを開き、`导出评论`ボタンをクリックすると、Twikooのコメントデータを`json`ファイルにエクスポートできます

![](/img/202310312344559.webp)

### 方法2（推奨）

`Twikoo`のコメントデータを`json`ファイルにエクスポートします。詳細は以下の記事をご覧ください：

>[Twikoo 评论数据导出教程 - iMaeGoo's Blog](https://www.imaegoo.com/2022/twikoo-data-export/)

## コメントデータの復元

単にデータをバックアップするだけで他に要件がないなら、ここまでで終了です。コメントデータの復元は、`导入`タブを選択し、ソースシステムに`Twikoo（JSON）`を選び、エクスポートしたバックアップファイルを選択してから`开始导入`をクリックするだけです。コメントデータを編集する必要がある場合は、このまま読み進めてください

## コメントデータの編集

`Visual Studio Code`やその他の`IDE`で、拡張子が`.json`の`Twikoo`コメントデータファイルを開けば、表示されるコメントデータを編集できます。以下のよく使われるデータの表の意味を参照して修正してください：

|   値    |             意味             |
| :-----: | :--------------------------: |
|  nick   |             ニックネーム             |
|  mail   |           メールアドレス           |
| mailMd5 |          メールアドレスのMD5値           |
|  link   |           ウェブサイトのリンク           |
|   ua    |          デバイス識別子          |
|   ip    |            IPアドレス           |
| master  |      コメントシステムの管理者かどうか     |
|   url   |      ホームページ基準の相対パス      |
|  href   | コメント送信時の現在位置の絶対パス |
| comment |           コメント本文           |
| isSpam  |         スパムかどうか         |
| created |          作成タイムスタンプ          |
| updated |          更新タイムスタンプ          |
| avatar  |           アバターのリンク           |
|   top   |           トップ固定かどうか           |

![](/img/202310312305132.webp)

変更が終わったら、自分の`Twikoo`コメントのデータベース（例えば私の場合は`MongoDB Cloud`）にアクセスし、`comment`の項目を削除します

![](/img/202310312351050.webp)

もちろん、より良い方法があればそれでも構いません。最終的に`comment`の項目を削除できれば大丈夫です...

削除が完了したら、上記の**コメントデータの復元**の手順を実行すれば変更完了です
