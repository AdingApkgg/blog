## サイトの中国語 URL にアクセスすると 404 になる

- WordPress のパーマリンクを投稿名 `%postname%` に設定し、タイトルが中国語のままだと、アクセス時に 404 が発生する。
- カテゴリ名やタグ名が中国語の場合も、アクセス時に 404 が発生する。
- URL リンクに中国語の文字や記号などが含まれている場合も同様。

![网站访问中文URL时遭遇404](/img/202304142300408.webp)

生成された URL に中国語が含まれるためサポートされず、404 が表示される。

## 解決方法

サイトディレクトリ内の wp-includes ディレクトリに入り、class-wp.php ファイルを編集する。

```php
找到$pathinfo         = isset( $_SERVER['PATH_INFO'] ) ? $_SERVER['PATH_INFO'] : '';
可以直接搜索$_SERVER['PATH_INFO']
将这行的第二个$_SERVER['PATH_INFO']替换为mb_convert_encoding($_SERVER['PATH_INFO'], 'UTF-8', 'GBK')
再找到list( $req_uri ) = explode( '?', $_SERVER['REQUEST_URI'] );
将$_SERVER['REQUEST_URI']替换为mb_convert_encoding($_SERVER['REQUEST_URI'], 'UTF-8', 'GBK')
```

上記の操作を実行して保存すれば、WordPress の URL で中国語の文字がサポートされるようになります！
